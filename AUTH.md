# Система аутентификации — ФинТрекер v2.0

## Обзор

Добавлена система аутентификации с паролем и админ-панелью для управления пользователями и семьями.

## Демо-аккаунты

### Супер-администратор (полный доступ)
- **Логин:** `admin`
- **Пароль:** `1968`
- **Права:** управление пользователями, семьями, полный доступ ко всем функциям

### Обычный пользователь
- **Логин:** `user`
- **Пароль:** `1234`
- **Права:** доступ к своим данным, ограниченное управление

## Функциональность

### 1. Страница входа (`/login`)
- Красивая форма входа с градиентным фоном
- Валидация логина и пароля
- Отображение ошибок при неверных данных
- Индикатор загрузки
- Подсказки с демо-аккаунтами

### 2. Защита маршрутов
- Все маршруты защищены `ProtectedRoute`
- Неавторизованные пользователи перенаправляются на `/login`
- После успешного входа происходит автоматическая перезагрузка

### 3. Админ-панель (`/admin`)
Доступна только для пользователей с ролью `SUPER_ADMIN`.

#### Управление пользователями:
- ✅ Просмотр списка всех пользователей
- ✅ Добавление новых пользователей
- ✅ Удаление пользователей (кроме супер-админа)
- ✅ Назначение ролей (USER, ADMIN, SUPER_ADMIN)
- ✅ Информация о количестве семей у каждого пользователя

#### Управление семьями:
- ✅ Просмотр списка всех семей
- ✅ Создание новых семей
- ✅ Удаление семей
- ✅ Добавление участников в семью
- ✅ Удаление участников из семьи
- ✅ Просмотр владельца и участников семьи

### 4. Роли пользователей

#### SUPER_ADMIN (Супер-администратор)
- Полный доступ ко всем функциям
- Управление пользователями и семьями
- Доступ к админ-панели
- Нельзя удалить

#### ADMIN (Администратор)
- Доступ ко всем функциям приложения
- Управление своей семьёй
- Нет доступа к админ-панели

#### USER (Пользователь)
- Доступ к основным функциям
- Управление своими данными
- Участие в семьях

### 5. Выход из системы
- Кнопка выхода в шапке (иконка `LogOut`)
- Кнопка выхода в настройках
- После выхода перенаправление на страницу входа

## Технические детали

### Структура данных

```typescript
interface User {
  id: string;
  login: string;
  password: string;
  name: string;
  role: UserRole;
  familyIds: string[];
  createdAt: string;
}

interface Family {
  id: string;
  name: string;
  ownerId: string;
  memberIds: string[];
  createdAt: string;
}

enum UserRole {
  SUPER_ADMIN = 'SUPER_ADMIN',
  ADMIN = 'ADMIN',
  USER = 'USER',
}
```

### Store аутентификации (`src/store/auth.ts`)

Используется Zustand с persist middleware для сохранения состояния в localStorage.

**Методы:**
- `login(login, password)` — вход в систему
- `logout()` — выход из системы
- `addUser(userData)` — добавление пользователя
- `deleteUser(userId)` — удаление пользователя
- `addFamily(name, ownerId)` — создание семьи
- `deleteFamily(familyId)` — удаление семьи
- `addMemberToFamily(familyId, userId)` — добавление участника
- `removeMemberFromFamily(familyId, userId)` — удаление участника

### Защита маршрутов

```typescript
// Обычная защита (требует авторизации)
<ProtectedRoute>
  <Dashboard />
</ProtectedRoute>

// Защита для админов
<AdminRoute>
  <AdminPanel />
</AdminRoute>
```

## Использование

### Вход в систему

1. Откройте приложение
2. Введите логин и пароль
3. Нажмите "Войти"
4. При успешном входе произойдёт перенаправление на дашборд

### Выход из системы

**Способ 1:** Нажмите иконку выхода в шапке
**Способ 2:** Перейдите в настройки и нажмите "Выйти"

### Админ-панель (только для SUPER_ADMIN)

1. Войдите как `admin` / `1968`
2. В боковом меню появится пункт "Админ"
3. Перейдите в админ-панель
4. Управляйте пользователями и семьями

### Создание нового пользователя

1. В админ-панели нажмите "Добавить" в разделе "Пользователи"
2. Заполните форму:
   - Логин (уникальный)
   - Пароль
   - Имя
   - Роль
3. Нажмите "Создать"

### Создание новой семьи

1. В админ-панели нажмите "Создать семью"
2. Введите название семьи
3. Нажмите "Создать"
4. Админ автоматически становится владельцем

### Добавление участника в семью

1. В админ-панели раскройте нужную семью
2. В разделе "Добавить участника" выберите пользователя из списка
3. Нажмите "Добавить"

## Безопасность

⚠️ **Важно:** В текущей реализации пароли хранятся в открытом виде в localStorage. Это допустимо для демо-приложения, но не рекомендуется для production.

### Рекомендации для production:
- Хэширование паролей (bcrypt, argon2)
- JWT токены вместо хранения паролей
- HTTPS для всех запросов
- Rate limiting для защиты от brute-force
- Двухфакторная аутентификация
- Сессии с таймаутом

## Тестирование

### Сценарий 1: Вход как админ
1. Откройте приложение
2. Введите `admin` / `1968`
3. Убедитесь, что появился пункт "Админ" в меню
4. Перейдите в админ-панель

1. Выйдите из системы
2. Введите `user` / `1234`
3. Убедитесь, что пункт "Админ" отсутствует в меню
4. Проверьте доступ к основным функциям

### Сценарий 3: Неверные данные
1. Введите неверный логин или пароль
2. Убедитесь, что появляется сообщение об ошибке
3. Проверьте, что вход не выполнен
