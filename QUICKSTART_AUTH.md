# 🔐 Быстрый старт — Система аутентификации

## Вход в систему

При первом запуске вы увидите страницу входа.

### Демо-аккаунты:

**Администратор (полный доступ):**
- Логин: `admin`
- Пароль: `1968`

**Обычный пользователь:**
- Логин: `user`
- Пароль: `1234`

## Что доступно после входа

### Для всех пользователей:
- ✅ Дашборд с обзором финансов
- ✅ Транзакции, бюджеты, регулярные платежи
- ✅ Чеки, категории, счета
- ✅ Отчёты и аналитика
- ✅ Управление семьёй
- ✅ Настройки и экспорт/импорт

### Только для администратора (`admin`):
- ✅ **Админ-панель** (пункт меню "Админ")
  - Создание и удаление пользователей
  - Создание и удаление семей
  - Управление участниками семей
  - Назначение ролей

## Выход из системы

**Способ 1:** Нажмите иконку выхода (🚪) в правом верхнем углу
**Способ 2:** Перейдите в Настройки → кнопка "Выйти"

## Админ-панель

После входа как `admin` в боковом меню появится пункт **"Админ"** с иконкой щита.

### Возможности:

#### Управление пользователями:
- Просмотр списка всех пользователей
- Добавление новых пользователей (кнопка "Добавить")
- Удаление пользователей (иконка корзины)
- Назначение ролей: Пользователь / Администратор / Супер-администратор

#### Управление семьями:
- Просмотр списка всех семей
- Создание новой семьи (кнопка "Создать семью")
- Удаление семьи (иконка корзины)
- Добавление участников в семью (раскройте семью → выберите пользователя)
- Удаление участников из семьи

## Примеры использования

### Создать нового пользователя:
1. Войдите как `admin` / `1968`
2. Перейдите в "Админ"
3. Нажмите "Добавить" в разделе "Пользователи"
4. Заполните форму:
   - Логин: `ivan`
   - Пароль: `password123`
   - Имя: `Иван Иванов`
   - Роль: Пользователь
5. Нажмите "Создать"

### Создать новую семью:
1. В админ-панели нажмите "Создать семью"
2. Введите название: `Семья Ивановых`
3. Нажмите "Создать"
4. Вы станете владельцем этой семьи

### Добавить участника в семью:
1. В админ-панели найдите нужную семью
2. Нажмите на название семьи, чтобы раскрыть
3. В разделе "Добавить участника" выберите пользователя из выпадающего списка
4. Нажмите "Добавить"

## Важные замечания

⚠️ **Безопасность:**
- Пароли хранятся в localStorage в открытом виде (для демо)
- Не используйте реальные пароли
- Для production необходима серверная аутентификация

🔒 **Защита:**
- Все маршруты защищены
- Без входа вы будете перенаправлены на страницу логина
- Админ-панель доступна только для `SUPER_ADMIN`

💾 **Хранение данных:**
- Данные пользователей сохраняются в localStorage
- При очистке браузера данные будут потеряны
- Используйте экспорт/импорт для резервного копирования

## Решение проблем

**Не могу войти:**
- Проверьте правильность логина и пароля
- Попробуйте демо-аккаунты: `admin`/`1968` или `user`/`1234`

**Не вижу пункт "Админ":**
- Вы вошли не как администратор
- Выйдите и войдите как `admin` / `1968`

**Хочу сбросить всех пользователей:**
- Очистите localStorage: `localStorage.clear()` в консоли браузера
- Перезагрузите страницу
- Демо-пользователи будут восстановлены
