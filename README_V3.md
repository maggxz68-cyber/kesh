# Семейный бюджет v3.0 — Полная переработка архитектуры

## 🎯 Основные изменения

### 1. Разделение ролей и изоляция супер-админа

**Супер-администратор (admin / 1968):**
- ❌ Не состоит ни в одной семье
- ❌ Не участвует в бюджетах, транзакциях, расходах
- ✅ Только управление админ-панелью и настройками
- ✅ Управление пользователями и семьями
- ✅ После входа автоматически перенаправляется в `/admin`

**Обычные пользователи:**
- ✅ Состоят в семьях
- ✅ Участвуют в бюджете, транзакциях, расходах
- ✅ Могут создавать свои семьи через регистрацию

### 2. Полная изоляция данных по семьям

Каждая семья имеет **отдельные**:
- 💰 Кошельки/счета
- 📊 Бюджеты
- 💸 Транзакции (доходы/расходы)
- 🏷️ Категории
- 🔄 Регулярные платежи
- 👥 Участники

**Архитектура хранения:**
```typescript
interface AppState {
  familiesData: Record<string, FamilyData>; // Данные по семьям
  // ...
}

interface FamilyData {
  accounts: Account[];
  categories: Category[];
  transactions: Transaction[];
  budgets: Budget[];
  recurringRules: RecurringRule[];
  familyMembers: FamilyMember[];
}
```

Все операции автоматически привязываются к `currentFamilyId` из auth store.

### 3. Регистрация семей по email

**Новая страница `/register`:**
- Регистрация по email (уникальный)
- Создание семьи при регистрации
- Пользователь автоматически становится владельцем семьи
- Валидация email и пароля

**Поля регистрации:**
- Имя
- Email (используется как логин)
- Пароль (мин. 4 символа)
- Название семьи

### 4. Демо-доступ для ознакомления

**Кнопка "Демо-доступ"** на странице входа:
- Не требует регистрации
- Предзаполненные демо-данные (15 транзакций, 5 счетов, бюджеты)
- Пометка "ДЕМО" в шапке
- Полный функционал для ознакомления

### 5. Сканирование чеков на мобильных

**Компонент `ReceiptScanner`:**
- Использование камеры устройства через `getUserMedia`
- Переключение между фронтальной/задней камерой
- Визуальная рамка для позиционирования чека
- Сохранение фото в формате JPEG
- Превью отсканированного чека
- Интеграция в форму добавления транзакции

**Доступность:**
- Кнопка "Сканировать" появляется только на устройствах с камерой
- Проверка через `'mediaDevices' in navigator`

### 6. Упрощение ролей

**Удалена роль ADMIN:**
- Оставлены только: `SUPER_ADMIN` и `USER`
- Супер-админ — только для системного управления
- Все остальные пользователи — обычные (USER)

## 🐛 Известные ограничения

1. **Демо-режим:**
   - Демо-данные нельзя редактировать в production
   - Нет защиты от случайного удаления

2. **Сканер чеков:**
   - Работает только на устройствах с камерой
   - Требует HTTPS для доступа к камере
   - Нет OCR (распознавания текста)

3. **Хранение данных:**
   - Данные хранятся локально в localStorage
   - Нет синхронизации между устройствами
   - При очистке браузера данные теряются
