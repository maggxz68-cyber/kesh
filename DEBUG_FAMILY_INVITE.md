## Возможные проблемы и решения

### Проблема 1: Кнопка "Пригласить" не видна

**Симптомы:**
- На странице "Семья" нет кнопки "Пригласить"

**Диагностика:**
```
🔍 Family page render: {
  isOwner: false,  // ← Проблема здесь
  ...
}
```

**Причина:**
- `currentFamily.ownerId` не совпадает с `currentUser.id`

**Решение:**
- Убедитесь, что вы вошли как владелец семьи
- Проверьте, что `currentFamilyId` установлен правильно

### Проблема 2: Ошибка "Только владелец семьи может приглашать участников"

**Симптомы:**
- При нажатии "Добавить участника" появляется ошибка

**Диагностика:**
```
🔍 handleInvite вызван
🔍 isOwner: false  // ← Проблема здесь
❌ Пользователь не является владельцем
```

**Причина:**
- Проверка `isOwner` не пройдена

**Решение:**
- Проверьте, что `currentFamily?.ownerId === currentUser?.id`
- Убедитесь, что данные не повреждены в localStorage

### Проблема 3: addFamilyMember не вызывается

**Симптомы:**
- В консоли нет логов от `addFamilyMember`

**Диагностика:**
- Проверьте, вызывается ли `handleInvite`
- Проверьте, не блокируется ли вызов проверкой `isOwner`

**Решение:**
- Проверьте логи `handleInvite`
- Убедитесь, что все проверки пройдены

### Проблема 4: Пользователь не создаётся в authStore

**Симптомы:**
- В консоли нет лога "✅ Пользователь создан в authStore"

**Диагностика:**
```
🔍 addFamilyMember вызван с данными: {...}
🔍 Auth state: {...}
❌ currentFamilyId не установлен  // ← или другая ошибка
```

**Причина:**
- `currentFamilyId` или `currentUser` не установлены
- Семья не найдена

**Решение:**
- Проверьте, что пользователь вошёл в систему
- Проверьте, что `currentFamilyId` установлен
- Очистите localStorage и войдите снова

### Проблема 5: Участник не добавляется в familiesData

**Симптомы:**
- В консоли нет лога "✅ Участник семьи добавлен"

**Диагностика:**
- Проверьте, вызывается ли `addMemberToFamily`
- Проверьте, обновляется ли `familiesData`

**Решение:**
- Проверьте логи `addFamilyMember`
- Убедитесь, что `set()` вызывается правильно

## Как использовать логи

1. **Откройте консоль браузера** (F12)
2. **Перейдите на вкладку "Console"**
3. **Войдите в систему**
4. **Перейдите на страницу "Семья"**
5. **Наблюдайте за логами**

7. **Анализируйте логи**

1. **Скопируйте все логи из консоли**
2. **Опишите шаги воспроизведения:**
   - Какой пользователь вошёл
   - Какая семья выбрана
   - Какие данные вводились
   - Что произошло после нажатия кнопки
3. **Приложите скриншоты:**
   - Страница "Семья"

## Временные решения

### Если ничего не помогает:

1. **Очистите localStorage:**
   ```javascript
   localStorage.clear()
   ```

2. **Перезагрузите страницу**

3. **Войдите снова**

4. **Попробуйте добавить участника**

### Если проблема с данными:

1. **Экспортируйте данные:**
   - Перейдите в "Настройки"
   - Нажмите "Экспорт данных"

2. **Очистите localStorage:**
   ```javascript
   localStorage.clear()
   ```

3. **Перезагрузите страницу**

4. **Войдите снова**

5. **Импортируйте данные:**
   - Перейдите в "Настройки"
   - Нажмите "Импорт данных"
   - Выберите файл
