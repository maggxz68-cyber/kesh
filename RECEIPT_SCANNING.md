# 📱 Сканирование QR-кодов чеков

## 🎯 Что реализовано

Полноценная система сканирования QR-кодов чеков по стандарту ФНС России с автоматическим распознаванием и заполнением данных.

## 📋 Как это работает

### 1. QR-код чека
На каждом фискальном чеке в правом верхнем углу есть QR-код, содержащий:
- **t** - дата и время покупки (формат: YYYYMMDDTHHMM)
- **s** - сумма чека
- **fn** - номер фискального накопителя
- **i** - фискальный номер документа
- **fp** - фискальный признак
- **n** - тип операции (1=приход, 2=расход, 3=возврат прихода, 4=возврат расхода)

Пример QR-кода:
```
t=20240115T1430&s=1500.00&fn=9280009100023456&i=12345&fp=1234567890&n=1
```

### 2. Процесс сканирования

1. **Откройте форму добавления транзакции**
2. **Включите опцию "Есть чек"**
3. **Нажмите кнопку "📷 Сканировать"**
4. **Разрешите доступ к камере** (при первом использовании)
5. **Наведите камеру на QR-код чека**
6. **Дождитесь автоматического распознавания** (1-2 секунды)
7. **Поля формы заполнятся автоматически:**
   - Сумма
   - Дата
   - Номер чека
   - Сумма по чеку
   - Дата чека
   - Название магазина

## 📲 Использование на Android

### Требования
- Android 5.0+ (Lollipop)
- Chrome, Firefox, Samsung Internet или другой современный браузер
- Камера устройства
- Разрешение на использование камеры

### Пошаговая инструкция

#### 1. Откройте приложение
```
Перейдите на сайт приложения в браузере
```

#### 2. Добавьте новую транзакцию
```
Нажмите "Добавить" → Выберите тип "Расход"
```

#### 3. Включите опцию чека
```
Прокрутите вниз до раздела "Чек"
Включите переключатель "Есть чек"
```

#### 4. Запустите сканер
```
Нажмите кнопку "📷 Сканировать"
```

#### 5. Разрешите доступ к камере
При первом использовании браузер запросит разрешение:
```
[Разрешить] - нажмите для доступа к камере
```

**Важно:** Если вы случайно запретили доступ:
- Откройте настройки браузера
- Найдите раздел "Разрешения" или "Настройки сайта"
- Включите доступ к камере

#### 6. Наведите камеру на QR-код
```
Расположите QR-код чека в рамке на экране
Убедитесь, что код хорошо освещен
Держите телефон неподвижно 1-2 секунды
```

#### 7. Дождитесь распознавания
```
После успешного сканирования:
- Сканер автоматически закроется
- Появится зеленая карточка с данными чека
- Поля формы заполнятся автоматически
```

#### 8. Проверьте и дополните данные
```
- Проверьте сумму и дату
- Выберите категорию расхода
- Добавьте описание (опционально)
- Нажмите "Добавить операцию"
```

## 🔧 Решение проблем

### Камера не работает

**Проблема:** Черный экран или сообщение об ошибке

**Решения:**
1. **Проверьте разрешения браузера:**
   - Android: Настройки → Приложения → [Ваш браузер] → Разрешения → Камера → Разрешить
   - В браузере: нажмите на иконку замка в адресной строке → Разрешения → Камера

2. **Перезагрузите страницу:**
   - Потяните вниз для обновления или нажмите F5

3. **Попробуйте другой браузер:**
   - Рекомендуется Chrome или Firefox

4. **Проверьте, что камера не используется другим приложением:**
   - Закройте другие приложения, использующие камеру

### QR-код не распознается

**Проблема:** Сканер работает, но не может прочитать код

**Решения:**
1. **Улучшите освещение:**
   - Включите вспышку или дополнительное освещение
   - Избегайте бликов на чеке

2. **Держите телефон неподвижно:**
   - Расположите телефон на расстоянии 15-20 см от чека
   - Убедитесь, что QR-код полностью виден в рамке

3. **Очистите камеру:**
   - Протрите объектив камеры мягкой тканью

4. **Попробуйте переключить камеру:**
   - Нажмите кнопку переключения камеры (↻) в правом верхнем углу

5. **Проверьте, что это действительно QR-код:**
   - QR-код должен быть квадратным с черными квадратами в углах
   - На чеках ФНС QR-код находится в правом верхнем углу

### Ошибка "Камера не найдена"

**Проблема:** Сообщение о том, что камера не обнаружена

**Решения:**
1. **Проверьте, есть ли камера на устройстве**
2. **Перезагрузите устройство**
3. **Обновите браузер до последней версии**
4. **Попробуйте другой браузер**

## 🎨 Интерфейс сканера

### Элементы интерфейса

```
┌─────────────────────────────────┐
│  [X]  Сканирование QR-кода  [↻] │  ← Заголовок
├─────────────────────────────────┤
│                                 │
│      ┌───────────────┐          │
│      │               │          │
│      │   Видео с     │          │  ← Область сканирования
│      │   камеры      │          │
│      │               │          │
│      └───────────────┘          │
│                                 │
│  Наведите камеру на QR-код     │  ← Инструкция
│  чека                           │
└─────────────────────────────────┘
```

### Кнопки управления

- **[X]** - Закрыть сканер
- **[↻]** - Переключить между фронтальной и задней камерой

### Визуальная рамка

Синяя рамка с угловыми маркерами показывает область, в которой должен находиться QR-код.

## 📊 Распознанные данные

После успешного сканирования отображается карточка с информацией:

```
✓ Чек распознан                              [Удалить]

Дата и время:        15.01.2024, 14:30
Сумма:               1 500,00 ₽
Операция:            Расход
ФН:                  9280009100023456
ФД:                  12345
ФП:                  1234567890
```

### Автоматически заполняемые поля

| Поле формы | Значение из QR |
|------------|----------------|
| Сумма | `s` (сумма чека) |
| Дата | `t` (дата и время) |
| Есть чек | `true` |
| Номер чека | `i` (фискальный номер) |
| Сумма по чеку | `s` (сумма чека) |
| Дата чека | `t` (дата и время) |
| Название магазина | `Чек №{фискальный номер}` |

## 🔒 Безопасность и приватность

### Что происходит с данными

1. **Сканирование происходит локально** на вашем устройстве
2. **Данные не отправляются на сервер** для распознавания
3. **QR-код обрабатывается в браузере** с помощью JavaScript
4. **Распознанные данные** сохраняются только в localStorage вашего браузера

### Разрешения

Приложение запрашивает только:
- **Доступ к камере** - для сканирования QR-кодов

Приложение НЕ запрашивает:
- Доступ к контактам
- Доступ к файлам
- Доступ к местоположению
- Другие разрешения

## 💡 Советы по использованию

### Для лучшего результата

1. **Используйте заднюю камеру** - она обычно имеет лучшее качество
2. **Обеспечьте хорошее освещение** - избегайте теней и бликов
3. **Держите телефон неподвижно** - это ускорит распознавание
4. **Располагайте QR-код полностью в рамке** - все 4 угла должны быть видны
5. **Очистите чек** - если он помят или загрязнен, разгладьте его

### Массовое сканирование

Если вам нужно добавить несколько чеков:
1. Отсканируйте первый чек
2. Сохраните транзакцию
3. Нажмите "Добавить" для новой транзакции
4. Повторите процесс сканирования

### Ручной ввод

Если QR-код поврежден или не читается:
- Вы можете ввести данные чека вручную
- Все поля формы доступны для редактирования
- Данные из QR-кода можно изменить после сканирования

## 🛠 Технические детали

### Используемые технологии

- **html5-qrcode** - библиотека для сканирования QR-кодов
- **URLSearchParams** - парсинг данных из QR-кода
- **MediaDevices API** - доступ к камере устройства
- **React Hook Form** - управление формой и автозаполнение

### Поддерживаемые форматы

- QR-коды чеков ФНС России
- Стандартные QR-коды с текстовыми данными
- URL в QR-кодах

### Производительность

- Распознавание занимает 1-2 секунды
- Работает даже на слабых устройствах
- Минимальное потребление батареи
- Не требует интернет-соединения для распознавания
