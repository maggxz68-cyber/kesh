### 4. Автоматическое обновление курсов валют с ЦБ РФ

**Что изменилось:**
- ✅ Добавлен сервис `exchangeRates.ts` для получения курсов
- ✅ Автоматическое обновление при каждом открытии приложения
- ✅ Использование API Центробанка России (ЦБ РФ)
- ✅ Резервный API на случай недоступности ЦБ

**Как это работает:**
```typescript
// При старте приложения
useEffect(() => {
  init();
  setupCrossTabSync();
  autoUpdateExchangeRates(); // ← Автоматическое обновление курсов
}, [init]);
```

**Источники данных:**
1. **Основной:** ЦБ РФ (https://www.cbr.ru/scripts/XML_daily.asp)
2. **Резервный:** ExchangeRate API (https://api.exchangerate-api.com)

**Поддерживаемые валюты:**
- ✅ RUB (российский рубль) - базовая валюта
- ✅ USD (доллар США)
- ✅ EUR (евро)
- ✅ KZT (казахстанский тенге)
- ✅ CNY (китайский юань)

**Формат данных:**
```typescript
interface ExchangeRate {
  id: string;
  baseCode: string;    // Например: USD
  quoteCode: string;   // Например: RUB
  rate: number;        // Курс: 92.50
  date: string;        // Дата обновления
  source: string;      // Источник: CBR или EXCHANGERATE_API
}
```

## 🎯 Как использовать

### Вход как супер-админ:
1. Откройте приложение
2. Введите логин: `admin`
3. Введите пароль: `1968`
4. Нажмите "Войти"
5. Перейдите в раздел "Админ" в меню

### Вход как демо-пользователь:
1. Откройте приложение
2. Нажмите "Демо-доступ"
3. Или введите: `demo` / `demo`
4. Вы попадёте в демо-семью с предзаполненными данными

### Создание новой семьи:
1. На странице входа нажмите "Создать свою семью"
2. Заполните форму:
   - Имя
   - Email
   - Пароль
   - Название семьи
3. После регистрации:
   - ✅ Вы автоматически становитесь админом семьи
   - ✅ Создаются стандартные категории
   - ✅ Создаются стандартные счета (с нулевыми балансами)
   - ❌ Транзакции не создаются (начинаете с чистого листа)

### Проверка курсов валют:
1. Откройте приложение
2. Курсы автоматически обновляются при каждом открытии
3. Проверить курсы можно в настройках или на дашборде
4. В консоли браузера (F12) можно увидеть логи обновления

## 🆘 Решение проблем

### Проблема: Не могу войти как админ
**Решение:**
- Логин: `admin`
- Пароль: `1968`
- Убедитесь, что не включён Caps Lock

### Проблема: Курсы валют не обновляются
**Решение:**
1. Проверьте интернет-соединение
2. Откройте консоль браузера (F12)
3. Посмотрите логи обновления курсов
4. Если есть ошибки - проверьте доступ к cbr.ru

### Проблема: Новая семья создаётся без категорий
**Решение:**
- Это нормальное поведение
- Категории создаются автоматически при первом обращении
- Если категорий нет - перезагрузите страницу

### Проблема: Не вижу админ-панель
**Решение:**
- Админ-панель доступна только супер-админу
- Войдите как `admin` / `1968`
- Обычные пользователи не видят этот раздел
