# 🔐 Учётные записи и демо-данные

## 👤 Демо-пользователь

При первом запуске сервера автоматически создаётся демо-пользователь для тестирования:

### Данные для входа:
- **Логин**: `demo`
- **Пароль**: `demo`
- **Роль**: FAMILY_ADMIN (администратор семьи)
- **Email**: demo@example.com

### Что включено в демо-аккаунт:
- ✅ Демо-семья "Демо Семья"
- ✅ 2 счёта (Наличные и Основная карта)
- ✅ 8 категорий расходов и доходов
- ✅ 20 демо-транзакций за последний месяц
- ✅ Полная функциональность для тестирования

## 👑 Супер-администратор

Для управления всей системой создан супер-администратор:

### Данные для входа:
- **Логин**: `admin`
- **Пароль**: `1968`
- **Роль**: SUPER_ADMIN (супер-администратор)
- **Email**: admin@system.local

### Возможности супер-администратора:
- 📊 **Обзор** - статистика по всем пользователям и семьям
- 👥 **Управление пользователями** - просмотр, удаление пользователей
- 🏠 **Управление семьями** - просмотр, удаление семей
- 💾 **Бэкап** - информация о хранении данных
- ⚙️ **Система** - системная информация

### Доступ к админ-панели:
1. Войдите как супер-администратор (`admin` / `1968`)
2. В меню появится пункт **"Админ"** (иконка щита 🛡️)
3. Нажмите на него для доступа к панели управления

## 🚀 Как использовать

### Для тестирования функциональности:
```bash
# 1. Запустите приложение
docker compose up -d

# 2. Откройте http://your-server-ip

# 3. Войдите как демо-пользователь
Логин: demo
Пароль: demo
```

### Для управления системой:
```bash
# 1. Войдите как супер-администратор
Логин: admin
Пароль: 1968

# 2. Перейдите в раздел "Админ"

# 3. Управляйте пользователями и семьями
```

## ⚠️ Безопасность

### Важно изменить пароли в production:

1. **Измените пароль супер-администратора**:
   - Войдите как `admin` / `1968`
   - Перейдите в настройки
   - Измените пароль на сложный

2. **Или создайте нового супер-администратора**:
   ```bash
   # Подключитесь к базе данных
   docker exec -it finance-backend sh
   sqlite3 /app/data/finance.db
   
   # Создайте нового админа (замените значения)
   INSERT INTO users (id, login, password, name, email, role) 
   VALUES ('new-admin-id', 'newadmin', '$2a$10$...', 'New Admin', 'admin@yourdomain.com', 'SUPER_ADMIN');
   
   # Удалите демо-админа
   DELETE FROM users WHERE login = 'admin';
   ```

3. **Или отключите демо-данные**:
   - Отредактируйте `server/index.js`
   - Закомментируйте блок "Создание демо-данных"
   - Перезапустите сервер

## 📊 API Endpoints для администратора

### Получить список пользователей:
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3001/api/admin/users
```

### Получить список семей:
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3001/api/admin/families
```

### Удалить пользователя:
```bash
curl -X DELETE \
  -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3001/api/admin/users/USER_ID
```

### Удалить семью:
```bash
curl -X DELETE \
  -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:3001/api/admin/families/FAMILY_ID
```

## 🆘 Решение проблем

### Демо-данные не создались:
```bash
# Проверьте логи сервера
docker compose logs backend

# Перезапустите сервер
docker compose restart backend
```

### Не могу войти как администратор:
```bash
# Проверьте, что пользователь существует
docker exec -it finance-backend sh
sqlite3 /app/data/finance.db
SELECT * FROM users WHERE login = 'admin';
```

### Админ-панель недоступна:
- Убедитесь, что вы вошли как `SUPER_ADMIN`
- Проверьте консоль браузера на ошибки
- Проверьте, что API endpoints доступны
