# 🔐 Система прав доступа и синхронизация

## ✅ Что было исправлено

### 1. Права доступа в семье

**Проблема:** При создании семьи пользователь получал роль USER и не мог управлять настройками.

**Решение:** Добавлена роль **FAMILY_ADMIN** (админ семьи):
- ✅ Владелец семьи автоматически получает роль FAMILY_ADMIN
- ✅ Админ семьи может:
  - Добавлять новых участников
  - Редактировать настройки бюджета
  - Управлять счетами
  - Управлять категориями
  - Редактировать все операции
  - Управлять регулярными платежами

**Роли в системе:**
- **SUPER_ADMIN** - системный администратор (admin/1968)
- **FAMILY_ADMIN** - админ семьи (владелец)
- **USER** - обычный участник семьи

### 2. Синхронизация между устройствами

**Проблема:** Изменения на одном устройстве не видны на другом.

**Причина:** Данные хранятся в localStorage каждого браузера отдельно.

**Решение:** Добавлена система синхронизации:

#### Способ 1: Код синхронизации
1. На первом устройстве создайте код синхронизации
2. Скопируйте код
3. На втором устройстве введите код
4. Данные синхронизируются автоматически

#### Способ 2: Файл синхронизации
1. Экспортируйте данные семьи в файл
2. Перенесите файл на другое устройство
3. Импортируйте файл
4. Данные синхронизируются

#### Способ 3: Синхронизация между вкладками
- Изменения автоматически синхронизируются между вкладками одного браузера
- Не требует дополнительных действий

## 📋 Как использовать

### Создание семьи с правами админа

1. **Зарегистрируйтесь** на странице входа
2. **Создайте семью** - вы автоматически станете FAMILY_ADMIN
3. **Управляйте семьей:**
   - Добавляйте участников
   - Назначайте роли
   - Управляйте всеми настройками

### Добавление участников в семью

1. Перейдите на страницу **"Семья"**
2. Нажмите **"Пригласить"**
3. Заполните форму:
   - Имя участника
   - Email
   - Роль (USER по умолчанию)
4. Нажмите **"Отправить приглашение"**

### Синхронизация данных

#### Между устройствами:

**Метод 1: Код синхронизации**
1. Откройте страницу **"Синхронизация"**
2. Нажмите **"Создать код синхронизации"**
3. Скопируйте код
4. На другом устройстве:
   - Откройте **"Синхронизация"**
   - Вставьте код
   - Нажмите **"Применить код"**
5. Данные синхронизируются

**Метод 2: Файл синхронизации**
1. Откройте **"Синхронизация"**
2. Нажмите **"Экспорт в файл"**
3. Перенесите файл на другое устройство
4. На другом устройстве:
   - Откройте **"Синхронизация"**
   - Нажмите **"Импорт из файла"**
   - Выберите файл
5. Данные синхронизируются

#### Между вкладками:
- Просто откройте приложение в новой вкладке
- Изменения синхронизируются автоматически

## 🎯 Система ролей

### SUPER_ADMIN (Системный администратор)
**Логин:** admin  
**Пароль:** 1968

**Права:**
- ✅ Управление всеми пользователями
- ✅ Управление всеми семьями
- ✅ Доступ к админ-панели
- ❌ Не участвует в бюджетах семей

### FAMILY_ADMIN (Админ семьи)
**Как получить:** Создать семью

**Права:**
- ✅ Управление участниками семьи
- ✅ Редактирование всех настроек
- ✅ Управление бюджетами
- ✅ Управление счетами
- ✅ Управление категориями
- ✅ Редактирование всех операций
- ✅ Управление регулярными платежами
- ✅ Просмотр всех данных семьи

### USER (Участник семьи)
**Как получить:** Быть добавленным в семью

**Права:**
- ✅ Создание своих операций
- ✅ Просмотр общих данных
- ✅ Просмотр своих данных
- ❌ Не может управлять настройками
- ❌ Не может добавлять участников

## 🔄 Синхронизация

### Что синхронизируется:
- ✅ Счета
- ✅ Категории
- ✅ Транзакции
- ✅ Бюджеты
- ✅ Регулярные платежи
- ✅ Участники семьи

### Что НЕ синхронизируется:
- ❌ Настройки пользователя (тема, базовая валюта)
- ❌ Данные супер-админа
- ❌ Курсы валют (общие для всех)

### Автоматическая синхронизация:
- ✅ Между вкладками одного браузера
- ✅ При изменении данных

### Ручная синхронизация:
- ✅ Между устройствами через код
- ✅ Между устройствами через файл

## 🆘 Решение проблем

### Проблема: Не могу редактировать настройки

**Причина:** У вас роль USER, а не FAMILY_ADMIN

**Решение:**
1. Попросите админа семьи повысить ваши права
2. Или создайте свою семью (вы станете FAMILY_ADMIN)

### Проблема: Изменения не видны на другом устройстве

**Причина:** Данные не синхронизированы

**Решение:**
1. Откройте **"Синхронизация"** на первом устройстве
2. Создайте код или экспортируйте файл
3. На втором устройстве примените код или импортируйте файл

### Проблема: Не могу добавить участника

**Причина:** У вас нет прав FAMILY_ADMIN

**Решение:**
1. Попросите админа семьи добавить участника
2. Или создайте свою семью
