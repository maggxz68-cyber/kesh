# 🔧 Диагностика и решение проблемы с демо-данными

## ⚠️ Если данные не отображаются

Если после очистки localStorage данные всё равно не отображаются, выполните следующие шаги:

## 📋 Шаг 1: Полная очистка и перезагрузка

### Способ 1: Через настройки приложения

1. Откройте приложение
2. Перейдите в **Настройки**
3. Найдите раздел **"Восстановить демо-данные"**
4. Нажмите кнопку **"Полная очистка и перезагрузка"**
5. Подтвердите действие
6. Приложение перезагрузится и создаст новые демо-данные

### Способ 2: Через консоль браузера

1. Откройте консоль браузера (**F12** или **Ctrl+Shift+I**)
2. Перейдите на вкладку **Console**
3. Выполните команду:
   ```javascript
   localStorage.clear()
   ```
4. Перезагрузите страницу (**F5** или **Ctrl+R**)

### Способ 3: Через настройки браузера

1. Откройте настройки браузера
2. Перейдите в раздел "Конфиденциальность" или "Данные сайтов"
3. Найдите сайт приложения
4. Удалите все данные для этого сайта
5. Перезагрузите приложение

## 🐛 Шаг 3: Диагностика проблем

### Проблема 1: Логи инициализации не появляются

**Причина:** `init()` не вызывается

**Решение:**
1. Проверьте, что `App.tsx` содержит:
   ```typescript
   useEffect(() => { 
     init();
     setupCrossTabSync();
     autoUpdateExchangeRates();
   }, [init]);
   ```
2. Убедитесь, что компонент `Layout` рендерится
3. Проверьте, что пользователь вошёл в систему

### Проблема 2: Логи показывают "отсутствуют или пусты", но данные не создаются

**Причина:** Ошибка в `createDemoFamilyData()`

**Решение:**
1. Проверьте консоль на наличие ошибок JavaScript
2. Убедитесь, что `defaultAccounts`, `defaultCategories` импортированы правильно
3. Проверьте, что `generateSeedTransactions` возвращает данные

### Проблема 3: Данные создаются, но не сохраняются

**Причина:** Проблема с `persist` middleware

**Решение:**
1. Проверьте, что `onRehydrateStorage` callback работает
2. Убедитесь, что localStorage доступен
3. Проверьте, что нет ошибок при сохранении

### Проблема 4: `currentFamilyId` не установлен

**Причина:** Пользователь не вошёл в систему или `loginDemo()` не вызвался

**Решение:**
1. Войдите в демо-режим через кнопку "Демо-доступ"
2. Или войдите как `demo` / `demo`
3. Проверьте, что `currentFamilyId` = 'demo-family-001'

### Проблема 5: Данные есть, но не отображаются в интерфейсе

**Причина:** Компоненты не используют computed getters

**Решение:**
1. Проверьте, что компоненты используют `store.transactions`, `store.accounts` и т.д.
2. Убедитесь, что computed getters вызывают `getCurrentFamilyData()`
3. Проверьте, что `getCurrentFamilyData()` возвращает данные

## 🧪 Шаг 5: Проверка данных в консоли

Выполните в консоли браузера:

```javascript
// Проверить состояние store
const store = JSON.parse(localStorage.getItem('finance-tracker-storage'));
console.log('Состояние store:', store);

// Проверить демо-данные
const demoData = store?.state?.familiesData?.['demo-family-001'];
console.log('Демо-данные:', {
  accounts: demoData?.accounts?.length,
  categories: demoData?.categories?.length,
  transactions: demoData?.transactions?.length,
  budgets: demoData?.budgets?.length,
  recurringRules: demoData?.recurringRules?.length,
  familyMembers: demoData?.familyMembers?.length,
});
```

### Полный сброс:

1. Откройте консоль браузера (**F12**)

   ```javascript

   sessionStorage.clear();
   indexedDB.deleteDatabase('finance-tracker-storage');
   ```

4. Откройте приложение заново
5. Войдите в демо-режим

1. Убедитесь, что JavaScript включён
2. Убедитесь, что localStorage доступен
3. Попробуйте другой браузер (Chrome, Firefox)
4. Отключите расширения браузера

1. Убедитесь, что проект собран без ошибок
2. Проверьте, что все файлы на месте

   ```bash
   npm run build
   ```
